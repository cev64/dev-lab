# Launch kit: use order

All drafts use {{SITE_URL}} as a placeholder. Replace it with the live address before posting. Every piece names nflverse as the data source or states that Fieldwren is not affiliated with the NFL. Charlie posts these himself.

1. group-chat.md: send first, in your own league chat. Friendly feedback comes before anything public.
2. x-posts.md: one post per day for three days; the link appears only in post 3.
3. linkedin.md: post once, after the first feedback has been fixed.
4. reddit.md: last. Rules for both subreddits are unverified, so read them on Reddit first, spend a couple of weeks commenting, and disclose that you built the site.

Wording rules: calm, numbers first, no exclamation marks, no emoji, no gambling language.
